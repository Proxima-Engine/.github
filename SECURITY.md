# Security reporting

This organization maintains public engineering projects and a separate hosted product.

## Public Proxima Engine repository

For vulnerabilities affecting the public Engine source, follow the repository's [private security reporting policy](https://github.com/Proxima-Engine/proxima-engine/blob/main/SECURITY.md).

**Do not publish exploitable vulnerability details in public issues, discussions, or pull requests.**

## Hosted Agata Proxima Cloud

For security concerns involving hosted accounts, organization data, billing, or the hosted service, contact **support@agataproxima.com**.

Do not send passwords, private keys, signing secrets, access tokens, or unnecessary customer data in an initial report.

## Safe research

Only test systems you own or have explicit permission to assess. Use synthetic tenants and disposable data. Do not access, modify, or retain another customer's information.
